# Stickers | 表情包图片仓库

公开图片文件，用于在聊天中以直链显示已整理的表情包。图片按含义命名，原有中文名称和情绪标签保留在 index.json。

CDN 格式: https://cdn.jsdelivr.net/gh/1585247217/stickers@main/images/<filename>

例如: https://cdn.jsdelivr.net/gh/1585247217/stickers@main/images/sticker-001-hug-dumbcat-eight.gif

jsDelivr 可能有缓存延迟；还可以使用 raw.githubusercontent.com 作为备选。

此仓库仅存放表情包图片与索引，不包含原有私有 MCP 服务或头像。表情包作品的权利归各自权利人所有；如需移除请联系仓库所有者。
